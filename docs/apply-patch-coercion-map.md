# apply_patch Coercion Map

This audit maps the current `apply_patch` coercion stack in `proxy/qz_tool_apply_patch.py`.

## 1. Current contract

- `apply_patch` is exposed to Codex as `custom_tool_call name=apply_patch`.
- `apply_patch_call` is forbidden/removed.
- This audit does not change the wire protocol.

## 2. Accepted input shapes

- **Canonical:** `{"operation": {"type": "...", "path": "...", "diff": "..."}}`
- **Qwen-observed (split):** `{"operation": {"type": "...", "path": "..."}, "patch": "diff_text"}`
- **Legacy envelope:** `{"patch": "*** Begin Patch ... *** End Patch"}`

## 3. Coercion path table

| Path Name | Parser Function | Strategy | Input Shape | Output Shape | Telemetry | Advisory |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Canonical | `_coerce_apply_patch_operation` | Strict | `operation` dict | Cleaned dict | Yes | None |
| Split | `_parse_apply_patch_arguments` | Fallback | `operation` + `patch` | Merged dict | Yes | None |
| Envelope | `_parse_apply_patch_arguments` | Last resort | `patch` string | Dict with `diff` | Yes | None |

## 4. Failure path table

| Detection | Parser Function | Result | Telemetry |
| :--- | :--- | :--- | :--- |
| Invalid JSON | `_parse_apply_patch_arguments` | `None` | `coercion_failed` |
| Unsupported Operation | `_coerce_apply_patch_operation` | `None` | `coercion_failed` |
| Missing Path | `_extract_partial_operation` | Partial envelope | `coercion_failed` |

## 5. Telemetry safety

Telemetry is generated by `inspect_apply_patch_arguments`.
- **Safe:** Metadata only (`patch_present`, `coercion_strategy`, etc.).
- **Excluded:** Raw content, arguments, patch body, diff, file paths.
- **Certainty:** Certain.

## 6. Advisory behaviour

- **Hard errors:** Surfaced for invalid calls via `_invalid_apply_patch_call_message`.
- **Silent coercion:** Successful coercions (including fallback/envelope paths) are currently silent.
- **Borderline success:** No advisory emitted for coerced inputs.

## 7. Recommended Slice B

- Add `coercion_succeeded` telemetry for successful fallback coercions.
- Add `coercion_failed` telemetry for malformed inputs (ensure consistency).
- Add edge-case tests (invalid JSON, partial envelopes).
- Keep `custom_tool_call` protocol unchanged.
